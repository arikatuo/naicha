## 证据与口径

已联网检索并打开10个品牌菜单；另用HTTP打开候选单品页读取名称、容量、热量和加料选项。主要目录/数值来源为第三方 [咖啡奶茶喝什么](https://www.nckfhsm.com/brands)，其声明资料收集自互联网，没有完整数值来源链。因此本稿没有把转载热量标成官方。
已打开[霸王茶姬官方健康计算器](https://qmproductcomput.bwcj.com/)；其说明整杯数据由第三方实验室检测，但动态页本轮没有逐配置取得数据。请用户优先用它替换霸王茶姬各条第三方参考值。另打开[蜜雪官方产品页](https://www.mxbc.com/product_strength.html)，确认主要产品构成，不据其声称整杯热量。
估算均明确写出假设的组成份量和加总过程，不是品牌配方。糖按约4 kcal/g、普通奶约60 kcal/100ml、奶精暂按约500 kcal/100g；实际奶基、份量、糖浆差异大，给宽范围。参考基础可见[香港卫生署常见食物热量表](https://www.studenthealth.gov.hk/sc_chi/resources/resources_bl/files/caloric_value_common_food.pdf)与[白砂糖参考](https://www.weihengag.com/home/food/detail/code/18-1-001)。范围是草稿合理波动范围，不是检验置信区间。
第三方有热量区间的暂取中点，不能将中点写成正常糖中杯的官方值。单个数字糖度和杯型映射未知；原始值在备注中保留。不额外加糖不等于整杯无糖。
异常处理：蜜雪冰鲜柠檬水网页标20 kcal却列出多个糖度，未确认配置，草稿按有糖配料暂估180 kcal（100–260），不能当成全糖20 kcal。蜜雪、奈雪菜单中有疑似海外/特殊店条目，本稿尽量筛选，但地区需逐项核实。
