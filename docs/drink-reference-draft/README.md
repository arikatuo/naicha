# 40品牌饮品与小料热量：人工核实稿

检索日期：2026-10-04。本次仅整理资料，未修改小程序饮品库、页面或用户记录。

## 已整理的范围

- 24个茶饮品牌、16个咖啡品牌，每品牌8款候选饮品，共320款。
- 29项通用小料、奶类、糖浆、奶油及额外浓缩参考。
- 饮品依据：16款官方参考、65款第三方参考、239款配料估算。
- 19款来源未给出热量范围，保留“未注明”，没有补造范围。

这是一版常见代表款候选资料，并非最新全菜单。没有逐门店确认在售，也未验证所有第三方数值。尤其第三方菜单目录可能混入历史款、海外版本、容量和糖度不匹配的数据。

## 怎么核实

Excel分为“饮品核实表”“小料核实表”“阅读说明”。可以按品牌、依据类型筛选。黄色栏填写核实状态、核实后的热量，原参考值保留作比较。来源链接、配方假设和待核实问题均在右侧列。

先核对是否在售及饮品名称，再核对杯型、冰热、糖度、自带小料，最后核对热量。同名饮品配置不同，不能直接合并。最优先核对常喝品牌与标为“配料估算”的款式。

“官方参考”只适用于引用来源的配置；麦咖啡部分数值由官方kJ换算为kcal并四舍五入。“第三方参考”是网页直接提供数值，不等于已验证。“配料估算”的链接主要支持名称与配料，热量是明确假设用量下的模型结果，并非品牌配方或实验检测。

参考范围主要是宽估算包络或核实容差，不是检测置信区间。小料表范围也是本稿用于核对的参考包络，不能称来源实测范围。海外原料营养标签仅作为计算参考，不直接代表中国大陆门店配方。

## 值得优先核对的疑点

1. 蜜雪柠檬水第三方20kcal未注明糖度，本稿没有按正常糖采用；180kcal是明确标注的配料估算。蜜雪部分目录可能混有地区版本。
2. 霸王茶姬官方有[热量计算器](https://qmproductcomput.bwcj.com/)，但本次未取得每款每配置的动态输出；相关条目没有标成官方数值。
3. 瑞幸8款来自[大陆官方产品页](https://www.lkcoffee.com/products)，仍需对照杯型和冰热配置；麦咖啡冰焦糖玛奇朵官网营养与冰奶铁相同，建议复核。
4. 挪瓦部分第三方旧款存在不合理容量，吾饮良品等有历史款风险；Seesaw需确认本地门店实际在售。太平洋本组主要参考香港菜单，大陆款式需核实。
5. 比星官方使用[BeanStar](https://www.beanstar.com/products)，第三方目录写Bestar。本稿按官方名归档；目录中的候选款是否确为同一品牌、当前在售，仍需确认。

## 防止小料重复计算

整杯参考值已经考虑默认自带料。珍珠、奶盖等只有“额外加一份”时再叠加。换奶应扣除原奶、增加替代奶；不能把一整份燕麦奶再加到原拿铁。半糖也不能将整杯热量直接减半。

通用小料表不意味着40品牌都能选这些小料。品牌实际可加项目、已查到的菜单线索及缺口见分组文档：

- [B组：爷爷不泡茶至柠季](part-b.md)
- [C组：林里至Manner](part-c.md)
