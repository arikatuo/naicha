# 10 个茶饮品牌参考草稿（B 组）

整理日期：2026-10-04。仅供人工核实，不直接导入小程序。共 80 条。

## 证据边界

- 1 条为第三方网页直接列的热量（幽兰拿铁 380 kcal）；其余 79 条均为研究者按公开名称/配料作的模型估算，不能称作已查到的品牌热量。
- 爷爷不泡茶来源为官方产品系列，但官网未列热量；官方菜单不能把估算升级成官方参考。其余主要使用第三方菜单索引，网页数量/排序在抓取时有变化，不证明当前每家门店有售。
- 本版覆盖招牌及代表性款，部分补充款为新品，不声称经销量验证的热门排名。
- 未公开容量保留“未注明”，模型暂以常规约 500 ml 的杯量估算；桶装、650 ml 及 414 ml 项已另外处理。所有乳、糖、小料份量是假设，必须先核实，尤其阿嬷、重小料和奶盖饮品。
- kcal 是方便核对的建议整数；range 为宽的情景范围，不是品牌测量置信区间。不得以“半糖”把整杯 kcal 除以二。
- includedToppings 写“推定/待核实”的信息尚未证实；标准热量已含该模型默认料，添加小料只有额外添加时才再叠加。

## 优先核实点

1. 幽兰拿铁第三方单品页有 380 kcal，但方法与糖度不明，原料标签混有咖啡/蛋糕，需核对。
2. 阿嬷手作官方常写作“阿嫲手作”；目录继续按用户“阿嬷手作”分组，商品名须以官方点单页面为准。
3. 益禾堂烤奶温度会改变默认杯型：冰饮大杯，去冰/常温/热为中杯，不能用同值覆盖。
4. 茶话弄浓缩奶油是基底的一部分，“奶油雪顶”是可选额外料；梅占摇红本身已有雪顶，不能重复计。
5. 书亦招牌含多种料、阿嬷 2.0 珍珠牛乳默认有奶冻，重小料模型不确定性最大。
