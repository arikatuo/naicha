# 数据扩充说明

来源：`40品牌饮品与小料热量_核实稿.xlsx`（320 款饮品、29 种小料、40 个品牌）。
目标：扩充现有品类，不是照单全收。热量仅供娱乐参考，不做可靠性区分。

## 结果

| | 之前 | 之后 |
|---|---|---|
| 品牌 | 8 | 28（奶茶果茶 20，咖啡 8） |
| 饮品 | 64 | 255（新增 191） |
| 小料 | 20 | 28（通用 +2，仅咖啡 +6） |

## 规则

- 现有品牌、饮品、小料一个都不改、不删（`tests/fixtures/original-data.json` 是快照，测试会逐项核对）。
- 与现有重复的饮品保留 app 原来的热量，不用 Excel 的数字覆盖。
- 不收：桶装、超大杯、特殊单品豆咖啡、同品牌多余的黑咖、被指定去掉的品牌。
- 杯型统一为「中杯 / 大杯」，热量按中杯、五分糖计，大杯 ×1.25。
- 咖啡饮品没有甜度选项；咖啡小料（浓缩、糖浆、摩卡酱、焦糖淋酱、打发奶油顶、燕麦奶）只在咖啡饮品和「自己搭」的拿铁里出现。
- 标签、图标由名字里的关键词自动判断，写在 `scripts/data-expansion/generate.py` 和 `utils/drink-icons.js`。
- 品牌图标全部是自制的统一样式（不使用任何品牌 logo 图片）：`data/brands.js` 里每个品牌有 `mark`（一到两个字）、`color`（柔和的浅色底）、`ink`（同色系的深色字，对比度 ≥ 4.5）。界面里是「小图标 + 名称 + 副标题」的横向卡片，和「常见饮品」同一种写法。新增品牌时只要填这三项。

## 文件

- `data/extra-drinks.js`：新增饮品（由脚本生成，也可以手改）
- `data/brands.js`：品牌，新增 `category: 'tea' | 'coffee'`
- `data/toppings.js`：小料，咖啡专用的带 `scope: 'coffee'`
- `data/tags.js`：新增「咖啡 / 奶咖 / 黑咖」标签
- `scripts/data-expansion/`：筛选和生成脚本（需要 Python + pandas + 那份 Excel）
